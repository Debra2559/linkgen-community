# 家里饭桌 · 家庭点餐小程序

家庭成员打开小程序 → 按分类点菜 → 提交订单；Owner（你）在订单页看到所有订单并标记完成。
后端使用**微信云开发**，无需自备服务器。

## 功能一览

| 角色 | 能力 |
| --- | --- |
| 家庭成员 | 分类浏览菜单、加购、填称呼+备注下单、查看自己的订单 |
| Owner | 以上全部 + 查看全部订单、按状态筛选、待处理角标、标记"做好了"/恢复待处理 |

## 目录结构

```
family-order/
├── app.js / app.json / app.wxss    # 全局入口与配置
├── pages/
│   ├── menu/                       # 点餐首页（左侧分类 + 右侧菜品滚动联动 + 购物车）
│   ├── cart/                       # 确认订单（谁点的 + 清单 + 备注）
│   ├── orders/                     # 订单列表（owner 状态筛选 + 快捷标记）
│   └── order-detail/               # 订单详情
├── utils/cloud.js                  # 云函数调用封装 + 格式化工具
└── cloudfunctions/                 # 云函数（需逐个部署）
    ├── login/                      # 静默登录，首个用户自动成为 owner
    ├── menuList/                   # 菜单读取，首次自动写入种子菜品
    ├── createOrder/                # 下单（服务端核价）
    ├── listOrders/                 # 订单列表（成员仅见自己，owner 见全部）
    └── updateOrderStatus/          # 改订单状态（仅 owner）
```

## 部署步骤（约 10 分钟）

1. **导入项目**：微信开发者工具 → 导入 `family-order` 目录 → 填入自己小程序的 AppID（`project.config.json` 里目前是 `touristappid` 体验号）。
2. **开通云开发**：工具栏点「云开发」→ 开通（免费额度够家庭使用），记住环境名。
3. **创建集合**：云开发控制台 → 数据库，新建 4 个集合：
   - `admins`
   - `categories`
   - `dishes`
   - `orders`

   权限全部设为「**仅创建者可读写**」即可——所有读写都经过云函数，云函数用的是管理员权限。
4. **部署 5 个云函数**：在 `cloudfunctions/` 下每个函数目录上右键 →「上传并部署：云端安装依赖」。
5. **编译运行**：首次打开会自动写入示例菜单，**第一个进入小程序的人自动成为 Owner**。

## 常见问题

### 报错 `-601034 没有权限，请先开通云开发或者云托管`

这个错说明云函数调用根本没到达云端，按顺序排查：

1. **AppID 必须是真实注册的小程序**，不能是「测试号 / touristappid」——测试号不支持云开发。
   没有的话去 [mp.weixin.qq.com](https://mp.weixin.qq.com) 免费注册一个（个人主体即可），
   然后在开发者工具右上角「详情 → 基本信息」里把 AppID 换成自己的。
2. **点工具栏「云开发」按钮完成开通**（同意条款，会自动创建一个默认环境，等 1~2 分钟初始化）。
3. 开通后仍报错：到「云开发控制台 → 设置 → 环境设置」复制**环境 ID**，
   填进 `app.js` 顶部的 `const CLOUD_ENV = ''`，保存重新编译。
4. 确认 5 个云函数都已「上传并部署」（云开发控制台 → 云函数里能看到它们）。

## 日常维护

- **改菜单**：云开发控制台 → 数据库 → `dishes` / `categories` 集合直接增删改（改 `name`/`price`/`desc`/`emoji`/`soldOut` 字段即可，MVP 未做小程序内菜单管理）。
- **加 owner**：在 `admins` 集合添加记录，`_id` 填对方的 openid（openid 可在 `orders` 集合记录里看到）。
- **售罄**：把某菜品 `soldOut` 改为 `true`，前端自动置灰。

## 设计说明

- **Owner 判定**：`login` 云函数查 `admins` 集合；集合为空时首个访问者自动写入。状态修改接口服务端强制校验 owner 身份，前端隐藏按钮只是体验优化。
- **防改价**：下单时云函数按 `dishes` 集合现价重新计算总价，不信任前端传值。
- **购物车**：存本地 Storage（`family_cart`），换页/退出不丢；下单成功自动清空。
- **订单权限**：成员只能查到 `_openid` 为自己的订单（云函数内过滤）。
- **已知取舍**：订单列表/详情目前取最近 20 单，家庭场景足够；后续量大可加分页或独立 `getOrder` 云函数。
