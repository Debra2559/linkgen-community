# PR-08：运营管理验收契约

## 核对结论

负责人最新 `main` 已经包含运营管理页和活动 Agent 的前端入口。本 PR 不重复改运营页面，而是补充回归契约，明确哪些能力属于本地演示、哪些能力必须等 CloudBase 环境联调。

## 当前覆盖能力

- 展示待审核数量和活动候选列表。
- 支持“待审核 / 全部活动”筛选。
- 支持活动候选通过发布、驳回和补充封面。
- 支持开启/暂停每日巡查。
- 支持配置来源类型、授权状态、来源 URL/关键词和保存。
- 支持手动立即巡查，并展示扫描汇总与通知状态。
- CloudBase 可用时走云函数；不可用时明确显示本地演示模式，不把演示数据误认为线上数据。

## 验收清单

1. 未连接 CloudBase 时，页面明确显示本地演示数据，不发送真实通知。
2. 运营人员可以在来源列表切换启用状态并保存配置。
3. 运营人员可以切换筛选并查看待审核候选。
4. 通过候选后，候选从待审核列表移出；驳回后状态可见。
5. CloudBase 可用时，页面显示云端数据并调用对应管理云函数。
6. 云函数失败时，页面回退到本地演示数据并展示错误原因。
