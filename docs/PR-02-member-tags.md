# PR-02：成员名片标签视觉化

## 背景

成员名片原先复用全局 `.tag` 样式，标签显示为低对比度的浅灰方块，与名片的身份信息层级不一致，也不容易让用户快速扫读成员的兴趣方向。

## 本次改动

- 仅在 `pages/member-detail` 增加成员名片专属标签类，不改标签数据、排序或通讯录筛选逻辑。
- 标签改为圆角胶囊形状，增加内边距、字重和边框，提升可读性。
- 按标签顺序循环使用珊瑚、薄荷、黄色三组负责人主线颜色，保持轻量的视觉区分。
- 使用现有主题变量（`--coral`、`--mint`、`--yellow`、`--sky` 等），不修改亮色主题基准值。

## 验收清单

1. 打开任意成员名片，标签显示为胶囊形状而非旧的浅灰方块。
2. 多个标签在一行放不下时自然换行，间距一致。
3. 标签文字仍为原始数据，点击成员名片及“交换微信/发消息”行为不变。
4. 成员没有标签时，不出现空白胶囊。

## 本地验证

```text
node scripts/validate-member-tags.js
node scripts/validate-linkgen-release.js
git diff --check
```

微信开发者工具中需手动验收：进入通讯录，打开至少一张含 1 个、2 个和 3 个标签的成员名片，检查浅色主线下的对比度与换行效果。

## 范围边界

本 PR 不包含通讯录筛选标签扩充、编辑名片自定义标签、暗色主题切换、CloudBase 或运营管理功能；这些需求保持独立 PR，便于负责人逐项审核。
