# PR-06：我的动态回归契约与验收说明

## 核对结论

负责人最新 `main` 已经包含“我的动态”页面，因此本 PR 不重复改页面实现，而是补充可重复执行的回归契约和验收文档，避免后续合并或重构时把已有能力删掉。

## 当前覆盖能力

- 从本地 Storage 读取当前用户资料和讨论数据。
- “我发起的”只展示当前用户发布的讨论。
- “我的回复”从讨论的 `commentsList` 中筛选当前用户的回复。
- 两个 tab 有数量统计和持续选中状态。
- 支持下拉刷新、空状态、创建讨论、编辑名片和返回“我的”。
- 点击讨论或回复可以进入对应的讨论详情。

## 验收清单

1. 在“我的”页面点击“我的动态”，能进入“我的动态”页。
2. 切换“我发起的 / 我的回复”时，tab 选中状态和列表内容同步变化。
3. 当前用户没有发帖或回复时，显示对应空状态和下一步按钮。
4. 当前用户发布一条讨论后，返回页面能在“我发起的”看到它。
5. 当前用户回复一条讨论后，返回页面能在“我的回复”看到它。
6. 点击列表项能进入原讨论详情；下拉刷新不会清空已有本地数据。

## 范围边界

当前实现使用本地 Storage，属于单机原型。接入 CloudBase 后，需要由负责人把帖子、回复、用户身份和权限查询迁移到云端；本 PR 不改数据表、云函数或登录方式。
