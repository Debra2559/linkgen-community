# PR-03：扩充通讯录筛选标签

## 背景

通讯录原先只有“全部、AI 产品、设计、独立开发、找搭子、线下活动”六个筛选项，无法覆盖现有成员数据中的 Agent、用户研究、内容创作等方向。

## 本次改动

在保留原有筛选逻辑和“全部”入口的前提下，补充与当前本地成员数据匹配的分类：

- AI 工具
- 内容创作
- 用户研究
- Agent
- AI 应用
- 开源

筛选仍通过成员已有 `tags` 字段精确匹配，不新增数据表、不改成员资料、不引入 CloudBase 依赖。横向滚动容器沿用负责人现有布局，标签较多时可左右滑动。

## 验收清单

1. 通讯录仍默认显示“全部”。
2. 点击新增标签后，成员列表只显示包含该标签的成员。
3. “AI 工具、内容创作、用户研究、Agent、AI 应用、开源”均能在当前种子成员中匹配到结果。
4. 搜索框与标签筛选可以叠加使用。
5. 不改变成员行布局、名片点击跳转和原有六个标签的行为。

## 本地验证

```text
node scripts/validate-contact-filters.js
node scripts/validate-linkgen-release.js
node --check pages/contacts/contacts.js
git diff --check
```

微信开发者工具中需手动验收：横向滑动标签栏，逐个点击新增分类，再点“全部”恢复列表；确认成员数和空状态文案正常。

## 范围边界

本 PR 不包含自定义标签、成员标签编辑、标签云数据表或暗色主题改造；这些继续拆分为后续 PR。
