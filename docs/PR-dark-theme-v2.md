# 暗色主题 v2：独立、可回滚、默认亮色

## 目标

从负责人最新 `main` 单独增加暗色主题，不合并旧的宽范围主题 PR。默认主题仍为负责人确认的亮色；用户主动在“我的”页面点击胶囊滑块后，才切换到暗色。

## 范围

- 新增 `linkgen_theme_v2` 本地偏好，未设置时固定返回 `light`，不会继承旧 PR 的 `linkgen_theme` 暗色状态。
- 复用旧版右上角胶囊滑块的位置和滑块交互：亮色滑块停在太阳侧，暗色滑块停在月亮侧。
- 通过 `theme-dark` 作用域变量覆盖页面背景、卡片、输入框、按钮、标签、筛选项和详情面板。
- 接入当前 `app.json` 中的全部页面，切换后新打开的页面保持同一主题。
- 同步微信导航栏和 tabBar 的颜色。

## 明确不改

- 不修改负责人亮色变量、亮色背景、亮色日历配色和亮色组件布局。
- 不修改 CloudBase、数据表、运营 Agent、我的动态等已有主线功能。
- 不合并旧 PR #4；旧 PR 的范围过大且主题只在部分页面生效。

## 验收清单

1. 清除/首次安装后进入小程序，默认是亮色。
2. 在“我的”右上角点击胶囊，滑块移动到月亮侧，当前页面变暗。
3. 从“我的”切换到发现、活动、通讯录、详情、编辑页，页面均保持暗色。
4. 切回亮色后，亮色页面与负责人主线视觉一致。
5. 重启开发者工具，主题偏好仍保持；删除 `linkgen_theme_v2` 后恢复亮色。
6. 日历、活动卡片、成员标签和表单输入在暗色下仍具备足够对比度。

## 本地验证

```powershell
node scripts/validate-dark-theme.js
node --check app.js
node --check utils/theme.js
git diff --check
```

微信开发者工具仍需在测试 AppID 下手动验收页面切换和导航栏，验收通过后再由负责人决定是否合并。
