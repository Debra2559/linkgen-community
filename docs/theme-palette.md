# LinkGen 主题色板

## 当前亮色主题（改动前）

| Token | 颜色 | 用途 |
| --- | --- | --- |
| `--bg` | `#fffaf1` | 页面背景 |
| `--card` | `#fffef9` | 卡片和内容容器 |
| `--ink` | `#161310` | 深色标题、主按钮 |
| `--text` | `#201b16` | 正文 |
| `--ink-soft` | `#5b5046` | 次级正文 |
| `--muted` | `#8f8275` | 辅助说明、占位文字 |
| `--coral` | `#ff713b` | 主强调色、链接、操作 |
| `--coral-soft` | `#fff0e3` | 强调色浅背景 |
| `--yellow` | `#ffd95c` | 标签、提示和活动色 |
| `--mint` | `#e9edc9` | 信息块背景 |
| `--sky` | `#e8eff4` | 浅蓝辅助背景 |
| `--line` | `#eee3d3` | 分隔线和边框 |

亮色主题中还存在少量页面级散落颜色，例如 `#fff`、`#eef4ef`、`#fff4d5`、`#e3f1e8` 和 `#e6e4f7`，后续应逐步迁移到语义化 token，避免主题切换时遗漏。

## 当前暗色主题（`codex/dark-theme`）

| Token | 颜色 | 用途 |
| --- | --- | --- |
| `--bg` | `#050816` | 深海军蓝页面背景 |
| `--card` | `#0d1428` | 卡片和内容容器 |
| `--surface-raised` | `#131d36` | 标签、次级按钮、浮层 |
| `--surface-input` | `#0a1122` | 搜索框和输入控件 |
| `--ink` | `#f5f7ff` | 反转后的标题、主文字 |
| `--text` | `#f5f7ff` | 正文 |
| `--ink-soft` | `#c8d0e6` | 次级正文 |
| `--muted` | `#8d9ab8` | 辅助说明 |
| `--coral` | `#9b7bff` | 蓝紫品牌强调色 |
| `--coral-soft` | `rgba(155, 123, 255, 0.16)` | 品牌强调浅背景 |
| `--yellow` | `#58d8ff` | Logo 青色高亮、提示 |
| `--mint` | `#173248` | 深青信息块背景 |
| `--sky` | `#10253d` | 深蓝辅助背景 |
| `--line` | `#202b46` | 暗色边框和分隔线 |
| `--success` | `#68d391` | 成功状态（预留） |

### 设计原则

- 保留 Logo 的蓝紫与青色识别度，不直接使用高亮纯白大面积铺底。
- 文字与背景保持足够对比度，卡片通过层级色区分，不依赖重阴影。
- 后续页面级硬编码颜色应优先替换为语义 token；数据库、云函数和业务逻辑不在本次主题改动范围内。
