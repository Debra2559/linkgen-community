# LinkGen 活动采集 Agent 方案

## 当前原型

运营管理页已支持：

- 监控 4 个公众号：赛博禅心、数字生命卡兹克、T-ONE创新中心、Link & Gen；另设公众号搜索发现入口。
- 监控小红书重点观察池，并设小红书搜索发现入口。
- 每个来源单独启停，统一设置每日巡查和质量门槛；来源可指定“社区活动”或“社区外精选”。
- 来源默认“待确认授权”，只有显式标记为已授权、自有来源或已确认公开链接后才会参与巡查。
- 支持已授权 RSS / Atom / Feed：先读取条目链接，再逐条解析活动页面。
- 网络重置、临时 DNS 失败、超时和 408/429/5xx 最多重试 2 次；解析失败、权限失败、内网地址和超大响应直接记录，不重复请求。
- 把内容识别为“活动”或“分享”，只有活动候选进入审核队列。
- 候选展示来源平台、来源账号、活动时间、地点、文章概要、原文链接、质量等级和活动图片状态。
- 巡查完成后展示微信通知状态；管理员通过后活动写入活动库，驳回后保留为未通过记录。
- 同一时间已有未超时巡查时，重复点击或定时触发会返回 `already_running`，避免重复抓取和重复通知。

当前状态：运营页已接入 CloudBase 优先链路。CloudBase 可用且管理员通过鉴权时，候选查询、来源配置、巡查、审批和驳回走云函数；未部署云函数时才显示明确标注的本地演示数据。真实采集仍取决于来源 URL、授权状态和平台连接器配置，不能仅凭公众号名称自动抓取。

已新增云函数：

| 云函数 | 用途 | 权限 |
| --- | --- | --- |
| `activityAgent` | 每日定时巡查、解析、分类、评分、去重、写入候选、发送订阅消息 | 定时触发；手动调用需 `admins` |
| `manageActivityAgent` | 查询候选、来源和运行记录；保存来源；启停 Agent | `admins` |
| `approveActivityCandidate` | 候选转入 `events`，写入审计日志 | `admins` |
| `rejectActivityCandidate` | 驳回候选，写入原因和审计日志 | `admins` |
| `updateActivityCandidate` | 管理员补充 Cloud Storage 活动封面 | `admins` |
| `listPublishedEvents` / `getPublishedEvent` | 用户端读取已发布活动与来源摘要 | 公开读取已发布记录 |
| `registerForEvent` | 社区活动报名、取消报名、满员校验 | 登录用户；服务端事务 |

运营页来源配置要求：每个来源同时保存来源名称、多个公开文章/页面 URL、平台授权状态、活动归属和启停状态。新增来源默认是“待确认授权”，必须由管理员显式选择“已授权 / 合作 Feed”“LinkGen 自有来源”或“公开链接（已确认可用）”后，Agent 才会访问。公众号与小红书来源如果提供 RSS / Atom / 合作 Feed，Agent 会逐条巡查；没有授权连接器时，只接收管理员主动配置的页面或合作方提供的链接，不把账号名称当成可抓取接口。

## 官方能力核验

调研时间：2026-08-11。以下结论以官方文档为准，平台审核和接口权限仍需用实际主体账号确认。

| 能力 | 官方入口 | 对 LinkGen 的结论 |
| --- | --- | --- |
| 小程序订阅消息 | [订阅消息开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/subscribe-message.html) | 管理员需先在小程序内主动订阅模板；服务端才能发送，不能把“每日巡查”理解成无授权群发 |
| 外部资料打开 | [web-view](https://developers.weixin.qq.com/miniprogram/dev/component/web-view.html) | 飞书、公众号文章等外部页面需要配置合法业务域名；未配置前使用复制链接兜底 |
| 定时任务 | [微信云开发定时触发器](https://developers.weixin.qq.com/miniprogram/dev/wxcloud/guide/functions/triggers.html) | 使用 7 段 Cron、UTC+8；定时采集应放云函数/独立服务，不放在小程序页面生命周期中 |
| 小红书开放能力 | [小红书开放平台](https://open.xiaohongshu.com/) | 有开放平台不等于可以搜索所有公开笔记；首版只接授权、合作来源或用户主动提交链接 |
| 微信服务号能力 | [微信服务号文档](https://developers.weixin.qq.com/doc/service/guide/) | 公众号内容接入需按账号授权、素材能力和平台规则确认，不能默认全量检索 |

## 生产数据流

```text
来源账号池
  -> 每日定时任务
  -> 授权连接器 / 白名单页面
  -> 正文与元数据提取
  -> 活动 / 分享分类
  -> 质量评分、去重、风险检查
  -> activity_candidates
  -> 微信通知管理员
  -> 管理员审批
  -> events
```

状态机：

```text
内容 --(解析)--> 待分类
待分类 --(识别为分享)--> 仅归档
待分类 --(识别为活动且达质量门槛)--> 待审核
待审核 --(微信通知)--> 等待审批
等待审批 --(通过)--> 精彩活动
等待审批 --(驳回)--> 未通过
已发布社区活动 --(报名)--> 已报名
已报名 --(取消)--> 可再次报名
```

## 候选字段

| 字段 | 用途 |
| --- | --- |
| `source_platform` | `wechat`、`xiaohongshu`、`official_site` |
| `source_account` | 公众号或小红书账号名称 |
| `source_url` | 原文链接，审批页可回看 |
| `cover_image_url` | 原文封面或活动主图，需记录来源和版权状态 |
| `article_summary` | 文章/笔记概要，不复制全文 |
| `content_type` | `activity` 或 `share` |
| `quality_score` | 质量评分及评分原因 |
| `field_evidence` | 标题、时间、地点、报名链接对应的原文证据 |
| `risk_flags` | 时间缺失、链接失效、广告、重复、版权等 |
| `scope` | `community` 写入社区活动；`featured` 写入社区外精选 |
| `event_fingerprint` | 标题、时间、地点指纹，防止同一活动跨链接重复 |
| `review_status` | `pending`、`approved`、`rejected`、`needs_recheck` |

## 质量规则

候选至少满足以下条件才进入管理员审批：

1. 有明确活动意图，而不是普通观点分享。
2. 有未来时间，或能从正文提取出待确认时间。
3. 有主办方或来源账号。
4. 有活动详情页或报名入口。
5. 与已有活动不存在明显重复。
6. 不是纯广告、抽奖、课程销售或无法核验的转载。

时间、地点、报名链接、活动图片都应保留“已提取 / 待核验”状态，Agent 不能自动发布。

## 微信通知

推荐顺序：

| 方案 | 适用场景 | 限制 |
| --- | --- | --- |
| 小程序订阅消息 | 管理员主动订阅后接收候选提醒 | 需要模板和用户授权，不能无条件无限推送 |
| 企业微信机器人 | 内部运营群实时提醒 | 需要企业微信群和 Webhook 管理 |
| 运营后台站内通知 | 作为必选兜底 | 管理员需要主动打开后台 |

生产环境建议至少同时保留订阅消息和后台未读数。通知内容只放标题、平台、质量分、时间和审核入口，原文全文与图片通过后台查看。

## 采集边界

- 小程序端不保存第三方 Cookie、密钥或登录态。
- 公众号和小红书优先使用账号授权、官方开放能力、用户主动粘贴链接和公开白名单页面。
- 不绕过登录、验证码、频控或平台反爬措施。
- 图片默认只做活动候选预览，正式展示前记录来源、授权状态和删除入口。
- 页面正文视为不可信数据，不能让正文内容触发工具调用、权限修改或自动发布。

## 实施顺序

1. CloudBase 数据库：`agent_sources`、`agent_runs`、`source_items`、`activity_candidates`、`audit_logs`。
2. Cloud Functions 定时任务：每天 09:00，失败重试、超时、限速和运行日志。
3. 首批接入官网/RSS/JSON-LD 和用户主动提交的公众号、小红书链接。
4. 接入分类、去重、质量评分和字段证据。
5. 接入管理员订阅消息或企业微信通知。
6. 运营后台完成审批，审批成功后写入活动库；活动页从 CloudBase 读取发布记录。候选的封面、来源链接、报名链接、文章概要、字段证据和风险标记一并保存。
7. 配置 `event_registrations` 集合后，社区活动报名由云函数维护人数；外部精选不创建社区报名记录。
