# PR-05：移除“我的名片”重复入口

## 背景

“我的”页面的数字名片卡片本身已经提供“编辑”入口，顶部未完成资料时也会提供“开始设置”。菜单里再次放置“我的名片”会造成重复入口，并让“我的 Link”列表的层级变得不清晰。

## 本次改动

- 从菜单列表中移除“我的名片”节点，而不是依赖菜单顺序隐藏。
- 保留名片卡片右下角的“编辑”入口。
- 保留未完成资料时的设置入口，以及预览页的编辑入口。
- 不删除编辑页面、不修改名片数据结构、不改变其他菜单项。

## 验收清单

1. 打开“我的”页面，菜单只显示“我的动态”“我的活动”和“运营管理”。
2. 点击数字名片卡片右下角“编辑”，仍可进入编辑名片页。
3. 新用户看到设置提示时，点击“开始设置”仍可进入编辑名片页。
4. 名片预览页的“编辑”按钮仍可用。
5. 其他三个菜单入口的布局和跳转不受影响。

## 本地验证

```text
node scripts/validate-profile-menu.js
node scripts/validate-linkgen-release.js
git diff --check
```

## 范围边界

这是一个纯前端导航去重调整，不涉及 CloudBase、登录、数据库或运营权限。
