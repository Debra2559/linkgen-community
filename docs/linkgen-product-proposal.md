# LinkGen 社区协作提案

> **[DO NOT MERGE — DISCUSSION ONLY]**
>
> 这是基于现有前端的讨论方案与本地原型，不代表项目负责人已经批准产品、运营或后端决策。它不会推送到上游主线。

## 一句话

LinkGen 不是把三个微信群搬进小程序，而是给活动和成员信息增加一个可检索、可协作的公共入口：活动日历负责“什么时候发生”，通讯录负责“可以认识谁”，发现页的活动任务负责“现在一起做什么”。

## 本次原型能体验什么

1. 发现页保留普通讨论，同时增加“活动任务／讨论”筛选。
2. 活动任务展示类型、关联活动、截止日期、人数进度和状态。
3. 发布入口可选择发起讨论或发布任务。
4. 任务支持“感兴趣”和“我想加入”两个动作。
5. 任务状态支持“招募中 → 进行中 → 已完成”，也可以取消。
6. 原有活动日历、通讯录和个人中心保持原有视觉与入口。

## 用户与权限

| 角色 | 能做什么 |
| --- | --- |
| 游客 | 浏览公开活动和公开讨论 |
| 已邀请成员 | 查看通讯录、编辑自己的资料、发布讨论/任务、参与任务 |
| 管理员 | 隐藏内容、处理举报、禁言/封禁成员、恢复误操作 |

成员资料由本人填写。微信号默认不公开，只有本人主动开启后，其他已加入成员才能看到。三个群各自使用邀请码只是为了后台记录来源，不会把社区拆成三个互不相通的区域。

## 明确不在本次范围

点餐、订单、支付、积分、群聊同步、自动读取微信群消息、自动抓取外部活动、生产环境部署，以及仓库中遗留的菜单/订单页面。本分支不会删除这些历史代码，只会在变更记录中说明它们不是当前产品功能。

## 负责人需要决定的事项

- 是否接受“发现页 = 普通讨论 + 结构化活动任务”。
- 是否以微信云开发作为首期后端。
- 谁负责管理员、内容运营和生产环境账号交接。
- 联系方式公开规则、举报日志保留期限和首批真实成员名单。

## 15 分钟体验路线

打开小程序 → 发现 → 切换“活动任务” → 打开任务 → 点击“我想加入” → 查看进度 → 回到发现 → 打开右下角发布入口 → 切换“发布活动任务”。
